# Alamia Booking Example

This example demonstrates how to build a booking and scheduling module on top of the Alamia SaaS Platform.

## Key Features Demonstrated
- Multi-tenancy using `TenantContext`
- Integration with external calendars (Google, Outlook) via the Kernel API
- Timezone handling and conflict resolution
- Role-based Access Control (ARBAC)

## Getting Started
1. Run migrations for this module.
2. Configure your timezone settings in the tenant dashboard.
3. Access `/booking` in your browser.
