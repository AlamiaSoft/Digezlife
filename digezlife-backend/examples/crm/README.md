# Alamia CRM Example

This example demonstrates how to build a Customer Relationship Management (CRM) module on top of the Alamia SaaS Platform.

## Key Features Demonstrated
- Multi-tenancy using `TenantContext`
- Advanced Database operations (JSONB for custom fields)
- Reporting and Analytics using Kernel Services
- Role-based Access Control (ARBAC) for sensitive customer data

## Getting Started
1. Run migrations for this module.
2. Ensure you have seeded the initial CRM permissions.
3. Access `/crm` in your browser.
